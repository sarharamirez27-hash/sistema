KORA · Trippy Animations
Versión portátil para Windows

PRIMER USO
1. Conserva junta toda la carpeta distribuida.
2. Abre KORA-Trippy-Animations.exe.
3. En el primer inicio, define y confirma una contraseña para el usuario `sarharf`.
4. Después, inicia sesión con `sarharf` y la contraseña que configuraste.

La aplicación guarda los verificadores de contraseña y los datos localmente en:
%APPDATA%\KORA-Trippy-Animations
No almacena las contraseñas en texto legible. No existe una contraseña predeterminada. Si olvidas la contraseña, solicita ayuda antes de borrar ese directorio: también contiene los datos de estudio.

FUNCIONES
- Cuadernos y apuntes con búsqueda.
- Buscador global, editor de código y bitácora de errores.
- Papelera con restauración de apuntes, código, errores y cuadernos.
- Tarjetas, cuestionarios, temas visuales y controles de accesibilidad.

El editor guarda el código como texto y no lo ejecuta. La aplicación no requiere instalación ni conexión a Internet para las funciones incluidas.
Windows puede mostrar SmartScreen porque este ejecutable no está firmado digitalmente.
